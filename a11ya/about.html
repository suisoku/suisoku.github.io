a11ya design prototypes

A browsable archive of 40 designs and presets, with eight comparison galleries. Start with Horizon, the current main theme, or explore the full design gallery.

What you can explore

Studio, Ledger and Desk; Opal, Silk and Contour; the Contour variations and calibrations; Astra Morrow, Relay and Forma; Silk Indigo, Lucent, Vivid, Arc and Horizon. Switch between overview, evidence, setup and simulated run views. Many studies offer French and English controls.

Live audit 10 preserves the latest Design layout with a fictional browser image. Its preview states, journal and enlarge/restore controls work locally; browser control is disabled.

Static demo limits

All projects, people, observations and results are fictional examples. Forms illustrate a workflow: they do not create accounts, send invitations, visit targets or run audits. Some studies save display preferences in this browser; other edits last only for the current visit. Demo JSON downloads contain fictional data. Do not enter sensitive information.

Horizon live-browser experiments 4–9 and the sandbox preview/desktop viewers are excluded because they require a local runtime. The remaining run screens are visual simulations. No VM, server, database or login is required.

This is a design archive, not the operational a11ya application or an accessibility certification. The private application, configuration, server scripts and research documents are not part of this publication.
